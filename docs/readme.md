# Manual

The manual is a flat, ordered set of documents. Start with [usage](usage.md),
then consult the subject-specific references as needed.

1. [Usage](usage.md): install the project, run the CLI, and run the optional R
   cross-check.
2. [Survey](survey.md): the simulated questionnaire, item generator, response
   styles, and location profiles.
3. [Scenarios](scenarios.md): every experiment and its settings.
4. [Outputs](outputs.md): the CSV, plot, findings, and Excel files produced by a
   run.
5. [Architecture](architecture.md): the code map and the boundaries between
   generation, analysis, scenarios, and output writers.
